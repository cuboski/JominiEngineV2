# The JominiEngine

This repository contains the development progress of the JominiEngine.
JominiEngine is a game engine which aims to support historical massively multiplayer online (MMO) games. The current implementation of the JominiEngine is focused on a period of history known as The Hundred Year War however a focus on scability and extensibility aims to support different time periods and systems.

## How to run JominiEngine

To run the JominiEngine project in full it is required that both the server and client are run.

How to run the server locally:
- Navigate to the following C# script, `JominiEngine/server/JominiEngine/Server.cs`.
- Locate the variable `host_name` within the `Server.cs` file and replace the value with the IPv4 address of the computer that is to run the server. (Note the IPv4 address as it will be needed to run the client.)
- - Finding IPv4 Address : https://support.microsoft.com/en-us/windows/find-your-ip-address-in-windows-f21a9bbc-c582-55cd-35e0-73431160a1b9.
- Navigate to the JominiEngine.sln file found within the server folder and build.
- Run the JominiEngine.exe found under `bin/Debug` or `bin/Release`

How to run the Client within the Unity Editor :
- Navigate to the following folder JominiEngine/JominiClient/Assets/Code/Scripts
- Open the `Controller.cs` script and change the value of the `ipAddress` variable to the IPv4 Address of the computer that is to run the server.
- Open the `TestTextClient.cs` script and change the value of the `IPAddress ip` variable to `NetUtility.Resolve($IPv4Address$)` replacing `$IPv4Address` with the IPv4 address of the computer that is to run the server.
- Run the project within the Unity Editor from the LogIn scene.

NOTE: Make sure that when a change is to be committed and pushed to this repository that you remove the IPv4 addresses within the files, especially if you are working from a personal computer. This will prevent the leak of sensitive information.

# Troubleshooting

## Client

Imports are being flagged as incorrect in code editor:
- In the Unity editor navigate to Window > Package Manager
- Press the refresh button at the bottom.
- If persists on specific imports, find them in the package manager and update them manually there.
- This problem is due to a disconnect between what Unity believes is imported and what the code editor has access to.
